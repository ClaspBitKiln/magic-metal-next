# QA-агенты сайта «Мэджик Металл»

Команда `npm run qa:production` получает полный список страниц из production `sitemap.xml` и запускает пять независимых проверок:

- Visual QA — desktop/tablet/mobile, переполнение, обрезанный текст и чрезмерные заголовки;
- Functional E2E — внутренние ссылки, поиск и металлокалькулятор;
- Accessibility — alt, доступные имена, H1 и main;
- Performance — время загрузки, сетевой вес и тяжёлые изображения;
- Content & SEO — метаданные, терминология и переносы номеров ГОСТ.

Функциональный и контентный агенты обходят все маршруты sitemap. Визуальный агент проверяет ключевые шаблоны на трёх разрешениях, чтобы прогон оставался быстрым и устойчивым.

Результаты: `qa-results/report.md`, `qa-results/report.json`, `qa-results/screenshots/`.
Код 1 возвращается при критичных или высоких проблемах, поэтому аудит можно подключить к CI после preview-деплоя.
