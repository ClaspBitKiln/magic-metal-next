# KomTender MVP: заказчики не ММК

Рабочая схема поиска:
1. Получаем список тендеров из KomTender.
2. Получаем полную карточку каждого тендера.
3. Исключаем заказчика ММК.
4. Проверяем описание и позиции на соответствие номенклатуре ММК.
5. Оставляем только «заказчик не ММК + товар из номенклатуры ММК».
6. Выгружаем результат в Excel.

В веб-режиме тестовый API key вводится на странице тендеров, хранится только в sessionStorage текущего браузера и передаётся серверу заголовком X-Komtender-API-Key. В репозиторий ключ не записывается.

Независимый локальный режим:
python scripts/komtender_test.py --pages 3 --scan 100

Скрипт запросит ключ интерактивно и создаст komtender_mmk_customers.xls. Это Excel Spreadsheet XML, который открывается Microsoft Excel и LibreOffice. Данные не генерируются: строки формируются только из ответов KomTender.
