# Справочник металлопроката без смысловых ошибок

Цель — выпустить понятный снабженцу и проектировщику справочник, в котором коммерческий прайс не подменяет сортамент стандарта, а каждое поле имеет одно техническое значение.

## Обязательный порядок

1. Зафиксировать источник и дату снимка. Различать нормативный размерный ряд и фактическое наличие.
2. Построить дерево `раздел → подраздел → номенклатура → исполнение/марка → размер` по смыслу продукции, не по расположению ячеек в прайсе.
3. Определить размерную схему для каждого подраздела до импорта. Для трубы это минимум `наружный диаметр или профиль` и `толщина стенки`; не объединять их до прохождения проверок.
4. Нормализовать написание стандартов, марок и размеров. Не угадывать стандарт по похожему названию.
5. Проверить нормативные факты по первичному тексту ГОСТ/ТУ или официальному каталогу производителя. Страница продавца подтверждает наличие, но не заменяет нормативный источник.
6. Присвоить статус только по установленному правилу источников: зелёный — «На складе»; жёлтый — «Наличие уточняется»; красный — «Под заказ».
7. Прогнать структурные и предметные инварианты, затем вручную проверить крайние и случайные строки каждого подраздела.
8. Не публиковать цену, поставщика, завод, регион, внутренний файл или коммерческие пометки, если пользователь не запросил их явно.

Перед реализацией или аудитом прочитать [схему и проверки](references/catalog-schema.md).

## Стоп-условия

- Не публиковать размер как соответствующий ГОСТ, если он не подтверждён текстом стандарта.
- Не обозначать позицию «На складе» только потому, что она существует по ГОСТ.
- Не переносить контекст левой таблицы прайса на правую без проверки заголовка и подраздела.
- Не исправлять сомнительное значение догадкой: пометить как ошибку импорта или «Наличие уточняется».

## Результат проверки

Сообщить: число источников, строк, разделов и подразделов; количество строк по статусам; покрытие размерными схемами; найденные/исправленные дефекты; контрольные примеры; дату проверки. Отдельно перечислить непроверенные нормативные утверждения.
