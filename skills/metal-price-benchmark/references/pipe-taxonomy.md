# Классификация труб для ценового расчёта

Перед поиском цены определи тип трубы. Цены разных групп не взаимозаменяемы.

| Группа | Ключевые стандарты | Обязательные поля сопоставления |
|---|---|---|
| Электросварная круглая общего назначения | ГОСТ 10704, 10705 | наружный диаметр, стенка, марка, группа/категория, длина |
| ВГП | ГОСТ 3262 | условный проход, стенка/серия, чёрная или оцинкованная, длина |
| Электросварная нефтегазопроводная | ГОСТ 20295, 31447, 31446 | диаметр, стенка, класс/группа прочности, исполнение, испытания |
| Бесшовная горячедеформированная | ГОСТ 8731, 8732 | диаметр, стенка, марка, группа поставки, термообработка, длина |
| Бесшовная холоднодеформированная | ГОСТ 8733, 8734 | диаметр, стенка, марка, состояние, точность, длина |
| Нержавеющая бесшовная | ГОСТ 9940, 9941 | диаметр, стенка, марка, термообработка, поверхность |
| Нержавеющая электросварная | ГОСТ 11068 и ТУ | диаметр, стенка, марка, поверхность, назначение |
| Котельная/паропроводная | ГОСТ и специальные ТУ | марка, категория, контроль, термообработка, изготовитель |
| Обсадная/НКТ/бурильная | ГОСТ 632, 633, 31446, API 5CT/5DP | наружный диаметр, масса/стенка, группа прочности, резьба, длина |

## Правила расчёта

1. Не подменяй наружный диаметр условным проходом.
2. При цене за метр используй массу 1 м из стандарта или официальной карточки производителя; геометрическую формулу используй только как контроль.
3. Для оцинкованной ВГП не применяй цену чёрной трубы.
4. Для бесшовной трубы не используй цену электросварной того же размера.
5. Для 09Г2С, легированных и нержавеющих марок не применяй цену Ст3/Ст20.
6. Трубы с дополнительными УЗК, гидроиспытанием, термообработкой, фаской, изоляцией или специальной приёмкой рассчитывай отдельной надбавкой.
7. Для немерной, мерной и кратной длины сохраняй разные котировки.

## Источники по назначению

- ОМК Маркет и Северсталь Маркет: открытая цена и остаток по ряду электросварных, ВГП и бесшовных труб.
- MC.ru и региональные сети: контроль розничного/складского уровня.
- ТМК и Уралтрубпром: проверка производимого сортамента и технических параметров; цена учитывается только когда опубликована для конкретной позиции.
- Metallotorg и 23met: поиск дополнительных продавцов и проверка диапазона по правилам доверия.
