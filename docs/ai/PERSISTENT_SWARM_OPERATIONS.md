# Постоянный рой «Сайт2» — первый безопасный контур

После merge в main GitHub Actions будет запускать шесть независимых наблюдателей собственного публичного каталога по понедельникам и четвергам 04:17 UTC и вручную через workflow_dispatch. Не круглосуточный процесс: регулярный запуск экономит ресурсы.

Каждый наблюдатель выдаёт JSON с заголовками, ссылками и выдержкой страницы, не утверждает наличие, цены или нормативную совместимость. Артефакты доступны 14 дней. У роя пока нет автоматического ИИ-анализа и исправлений: это работающий после теста слой сбора наблюдений, не полноценные автономные агенты. Шесть задач работают с max-parallel=3, fail-fast=false, без секретов, прав на запись, заявок или деплоя.

До merge проверить CI и тестовый запуск; при ошибках оставить PR черновым. В дальнейшем добавлять доказательную сверку и ИИ-анализ только если он даёт измеримую пользу. Не трогать локальную копию второго аккаунта.
