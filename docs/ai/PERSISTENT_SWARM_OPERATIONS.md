# Разовый рой аудита каталога «Сайт2»

**Правило владельца:** каталог проверяется один раз по полной матрице, исправляется и утверждается. Постоянно наблюдать собственные разделы не требуется.

## Работа
1. Вручную запустить `Research swarm (safe, read-only)` при первоначальном аудите каталога или при существенной переработке, а не по расписанию.
2. Шесть параллельных направлений делают снимок разделов; результаты сохраняются как артефакты GitHub. Это сборщики, **не ИИ-эксперты**, не подтверждают ГОСТ или наличие.
3. По каждому товару проверить размерный ряд, марку стали/сплава, исполнение, применимые стандарты, CTA/заявку. Ошибки и пробелы — в единый список, затем точечные PR.
4. Нормативно проверить спорные параметры и принять явное решение: **утверждено / требует исправления / данных недостаточно**. Утверждение фиксировать в версии матрицы и связанном PR.
5. После утверждения больше не мониторить неизменённый каталог. Повторно проверять только изменённую позицию или при новых требованиях/доказанных ошибках.

## Безопасность
Workflow доступен через ручной `workflow_dispatch`, без `schedule`, без публикации на сайт, отправки коммерческих заявок и доступа на запись. Параллельность 3; шесть направлений. Результаты сохраняются 14 дней.
