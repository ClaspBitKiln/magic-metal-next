Не считать глобальную память другого аккаунта автоматически перенесённой.

## Установка на другом компьютере

Новый аккаунт ИИ на прежнем Windows не требует переустановки программ. Если меняется сам компьютер, сначала восстановить данные и установить необходимое:
- Node.js: https://nodejs.org/ ; проверить `node --version`, `npm --version`, `npx --version`;
- Chrome: https://www.google.com/chrome/ ; создать рабочий профиль под нового пользователя, не переносить чужие cookies;
- Obsidian: https://obsidian.md/ ; восстановить исходный vault из проверенной копии, открыть его, проверить `.obsidian` и плагины;
- Git: https://git-scm.com/ ; для разработки также проверить доступ к нужному репозиторию;
- Python — только если нужен конкретный вспомогательный скрипт, выбрать реально установленную рабочую версию.

После ручного успешного запуска RDC восстановить автозапуск под действительные пути. На новом Windows не переносить вслепую путь кэша _npx, device.json, DPAPI или конфиг другого пользователя. Проверить подключение после выхода/входа и перезагрузки; при переносе vault убедиться, что это прежние заметки, а не пустая новая папка.

Если приложение ИИ не показывает RDC-инструменты, найти/подключить Remote Desktop Commander в приложениях данного аккаунта и авторизовать существующий аккаунт сервиса. Если список устройств пуст, проверить аккаунт/разрешения и включённый компьютер; отсутствие устройства не является само по себе поводом удалить прежнюю привязку. Нельзя гарантировать вход в сервисы одной скопированной инструкцией: обязательные личные авторизации выполняет владелец.

## Диагностика по фактическому отказу

| Наблюдение | Что проверить | Чего не считать доказанным |
|---|---|---|
| RDC отсутствует | Приложения нового аккаунта и поиск доступных инструментов | Что клиент Windows неисправен |
| RDC Online, файл не читается | Устройство, путь, права и существующий vault | Полный доступ по одному статусу Online |
| CDP9223 недоступен | Нужный Chrome-профиль и loopback на Windows | Что надо закрыть все браузеры |
| «Вошёл», но видна форма входа | Та ли машина/вкладка/профиль; появился ли кабинет | Что пользователь не входил на другом устройстве |
| ObsidianMCP не отвечает | Запущен ли Obsidian, плагин, порт, ключ процесса, handshake | Что потерян файловый vault |
| Git/Vercel403 или401 | Существующий аккаунт, права, команда и окружение | Что нужен новый проект/аккаунт |
| Gmail не находит письмо | Правильный ящик, корпоративная почта, целевой поиск | Что письмо не поступало никуда |
| API/Firecrawl429 или лимит | Ограничение и разрешённое время повтора | Что повтор запроса сразу поможет |
| Save дал timeout/потерю stdout | Квитанция, текущий кабинет и конкретная запись | Что сохранения не было |
| HTTP200, форма пустая | Завершилась ли навигация, нужный ли режим и есть ли поля | Что товар принят или что точно сломан сервер |
| LastTaskResult0 | Когда был запуск и произошёл ли следующий самостоятельный цикл | Будущую исправность задания |

При неизвестном исходе внешней записи сначала чтение. Не нажимать finalSave повторно, пока не понятен результат предыдущей попытки. Не угадывать скрытый API и не пытаться исправлять лимиты обходом правил площадки.

## Условия работы с карточками и продвижением

Контактное лицо во всех согласованных размещениях — Юртаев Илья. Приём клиентов: Челябинск, Гостевая, 3, оф.306; юридический адрес Братьев Кашириных, 164 не обозначать автоматически устаревшим. Не придумывать адрес/юрлицо/склад в Узбекистане или Казахстане. Язык подбирать по площадке и аудитории; ссылка https://magicmet.ru — по её правилам.

Компания занимается снабжением промышленности, строительства и нефтегазовых предприятий. Опыт более 20 лет относится к ключевым специалистам, не к возрасту юридического лица. Срочные поставки и авиадоставка материалов ранее согласованы как предлагаемые услуги; возможность, маршрут и срок конкретного заказа подтверждаются, не гарантируются для любой позиции.

Цель по Узбекистану — прямые поставки дефицитных/срочных позиций конечным покупателям. Не утверждать дефицит только по широкому коду HS или наличию объявления. Проверять местное производство/остатки, дилеров и прямые поставки завода. Таможенная стоимость USD/т не является розничной ценой точного SKU. Сравнивать конечную стоимость покупателя с сопоставимым местным предложением и учитывать кредитование/отсрочку. Срочная поставка из РФ не автоматически быстрее местного склада.

Согласованные направления: конструкционные стали в листах и кругах, листСт3/09Г2С 4–200 мм, поковки, рельсы, бесшовные трубы, электроды, проволока, алюминиевые плиты/круги, СДТ; ранее также крупные уголки, швеллеры и балки. ДляСДТ использовать номенклатуру УралАрм и других заводов, цены mc.ru/Металлоторг по точному изделию. Разделять бесшовные/сварные/штампосварные исполнения и применимые нормативы. Присутствие09Г2С в соседнем варианте селектора не доказывает эту марку у базового изделия.

Расчётные формулы:
закупка net = закупка gross /1,22;
входнойНДС = gross − net;
логистика/оформление = (450 000+30 000)/20 =24 000 ₽/т;
резерв =5%×(net+логистика), если используется это допущение;
нижний порог предложения =gross+логистика+резерв и прочие относящиеся расходы.

Это заданная владельцем модель, а не обещание чистой прибыли. ВозвратНДС условен, финансируется заранее; учитывать прочие затраты/риски сделки. Правило владельца «минимум22% после возврата» было уточнено как продажа не ниже закупки gross плюс расходы, а не22% маржа от выручки. Налоги/пошлины покупателя не являются доходом продавца.

ЭкспортныйНДС0% и СТ-1 применяются при соблюдении законных условий. Российский склад не доказывает российское происхождение. Проверить точную форму/марку/HS10/НТД и актуальные ограничения на дату сделки. Предварительная проверка стандартного SKU не заменяет документы партии, проверку покупателя/конечного применения и лицензирования по 183-ФЗ ст.20/24. Обычные позиции7307/прокат не дают автоматического допуска любой специальной военной/ядерной детали.

Поддержке Prom уже направлялся вопрос о противоречии бесплатного лимита; не дублировать письмо из-за нового аккаунта. Отсутствие оплаты на форме не доказывает бессрочную бесплатность всех услуг. Платные опции не включать, CAPTCHA/SMS проходить штатно.

## Сайт, аналитика и границы работы

Сохранять утверждённый вариантА, бренд, hero, раздел #about, клиентские логотипы, контакты и обработку заявок. В карточках — минимализм, понятные параметры, существующие подвиды, простой выбор, корректные переходы к материалам/справочнику. Не создавать фиктивные страницы марок и нормативную совместимость.

Подробные материалы — направление справочника/MATBOOK, сейчас отдельный проект не развивать. CMS/Neon/CRM отложены. Исключённый P3 не возвращать из старого плана. Новая текущая задача владельца может разрешать конкретные новые товары; не применять старый запрет расширения каталога вопреки её явному объёму.

Проверки выбирать по AGENTS: текст/CSS — профильный сценарий; каталог — нужные тесты данных/поиска; конфигурация/маршруты — необходимые проверки сборки. Перед публикацией приложения соблюдать требуемые линтер/сборку для всей пачки, а не после каждой мелочи. Документы не требуют production сборки. При UI правках читать типографический skill и проверять изменённый экран/масштаб/overflow. Полный E2E без основания не запускать.

Для проверки заявок не отправлять настоящие тестовые письма на каждом старте. Ранее тесты уже проводились; новый действительный тест делать только по текущему основанию. Последний HTTP200 главной не является проверкой почты.

Vercel billing: https://vercel.com/claspbitkiln/~/settings/billing . Остановка по лимиту, приложение READY, DNS, доступ API и фактическая работа страницы — разные состояния. Не лечить каждую неисправность redeploy.

Удаление программ/кэшей/файлов — только по действующему согласованному списку. Старое согласие на очистку не переносится автоматически на новый запуск. Старые цифры свободного места не являются текущим измерением; перед тяжёлой установкой/сборкой проверить диск.
