# Ссылка на подбор и возврат к выбранным размерам: 17.10.2026

Подбор сохраняется в адресе текущей статической страницы. `size_N` и
`wall_N` относятся к таблице `sizes-series-N`; параметры разных таблиц
независимы. Сохраняются посторонние параметры адреса, например utm_source.
«Ссылка на подбор» появляется при выборе хотя бы одного параметра.
Можно скопировать адрес ссылки или открыть её в другой вкладке.

Использован поддерживаемый Next.js native History API без изменения
маршрутов, серверных searchParams, CDN-режима, зависимостей и форм.
Каждое изменение добавляет состояние в историю; «Назад»/«Вперёд»
восстанавливают селекторы, строки и ссылку заявки. Очистка одной таблицы
не сбрасывает остальные. При загрузке ссылки нужные таблицы открываются.
Существующие порядковые идентификаторы нельзя переиспользовать для другого
исполнения: добавление серий должно сохранять прежние идентификаторы.

Значение диаметра/сечения проверяется по существующим вариантам;
толщина проверяется по нормализованному числовому ряду. `4,0` распознаётся
как `4`, неизвестные значения не превращаются в ближайший размер.
Показывается предупреждение о нераспознанной части ссылки. Сочетание,
которого нет в таблице, сохраняет прежнее честное пустое состояние.
Особые условия и скобочные размеры остаются в контексте заявки.

Выбранная стенка выделяется mark внутри исходной ячейки. Остальные
номиналы остаются видимыми; исходный textContent и скобки сохраняются.
Ровно 4,0 не подсвечивает 14 или 4,5. Сброс убирает подсветку.
Клиентский код не получает новую копию таблицы и не запрашивает каталог.
Без JavaScript селекторы скрыты и доступна полная нормативная таблица;
фильтрация URL на сервере в этой версии не выполняется.

## Проверка

90 профильных тестов прошли, один существующий приватный тест пропущен.
Полный ESLint и production-сборка webpack проходят. Полная чистота типов
не заявляется: используется штатный SIMPLE_PUBLIC_SITE_BUILD.

Проверка браузером включает выбор 108×4, историю, перезагрузку, открытие
коллегой в другой вкладке, независимые серии балки, неверные параметры,
десятичную запятую, скобочные размеры, сохранение текста строк и работу
без JavaScript. Запросы POST/формы и сторонние запросы заблокированы.

При перехвате всех запросов Playwright отключает HTTP-кеш. Chromium может
повторно проверить favicon `/images/logo.png` при изменении истории.
Это отдельно записывается в артефакты; отсутствие любых сетевых запросов
не заявляется. Проверка запрещает повторные запросы HTML, каталога,
скриптов и CSS при смене фильтра. Перезагрузка и открытие новой вкладки,
разумеется, выполняют обычную загрузку страницы.
