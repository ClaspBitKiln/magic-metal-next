# Единые правила просмотра размеров

Запрос: неудобно читать горячекатаный лист; применить общий принцип ко всем
аналогичным страницам и сравнить крупные российские торговые каталоги.

## Исследование

Через Firecrawl просмотрены доступные HTML/markdown торговых страниц:

- ЕВРАЗ Маркет, горячекатаный лист: отдельные фильтры толщины S, ширины B,
  длины L; размеры повторяются в результатах.
- Мечел-Сервис, горячекатаный лист: «Выбор по параметрам», размерные поля,
  применение/сброс фильтров, отдельная документация, возможность оставить заявку.
- E-Металл, статья о сортаменте: компактные строки «толщина → формат»;
  сокращённая торговая таблица не заменяет полный нормативный ряд.
- ros-met.com: раздельные таблицы по видам листа.

Источники исследования (служебно, не ссылки в интерфейсе):
`https://chelny.evraz.market/metalloprokat/listy/list_goryachekatanyy_g_k/`,
`https://mechelservice.ru/catalog/list_goryachekatanyy/`,
`https://e-metall.ru/blog/sortament-listovogo-prokata/`,
`https://ros-met.com/list-stalnoj-razmery-tablitsa/`.

По дополнительному запросу просмотрен именно торговый каталог E-Металл:
`https://e-metall.ru/list/goryachekatanniy/`. Подтверждены быстрые ссылки
по толщине, отдельные группы «Толщина»/«Размер», диапазон, применение
и сброс, а также повтор размеров в результатах. На наш нормативный
справочник переносится принцип сужения списка, а не список складских позиций.
Существующий выбор интервала первого столбца не выдаётся за выбор произвольного
точного номинала: опции буквально соответствуют группам исходной таблицы ГОСТ.

23met.ru вернул HTTP429 и страницу CAPTCHA; HardHub (основной и региональный
каталоги листа) вернул HTTP403. Их текущие полные интерфейсы не проверены.
Не обходились проверки и не выполнялись повторные запросы 23met после CAPTCHA.
Исторический снимок размеров не считается доказательством текущего интерфейса.

Металлсервис: основная страница завершилась timeout, страница толщины 10 —
ошибкой proxy tunnel; полный просмотр не подтверждён. Веста — антибот-страница,
не использована как проверенный пример. Это качественное сравнение интерфейсов,
а не исследование с участием покупателей или доказательство роста конверсии.

## Реализация

Общий ProductSizeSeries на всех 34 карточках с числовыми таблицами:

- в длинных таблицах (>24 строк) выбор значения первого столбца и сброс;
- варианты берутся только из существующих строк, интервалы не интерпретируются
  как произвольная совместимость размеров;
- у листового проката форматы раскрыты по умолчанию, номинальные перечни
  остаются отдельной справкой; порядок данных в источнике не менялся;
- мобильный текст таблиц 14px вместо 12px; подписи единиц, закреплённые
  заголовки/первый столбец и горизонтальная прокрутка сохранены;
- фильтр меняет видимость серверных строк, не дублирует данные таблицы
  в клиентском состоянии и не выполняет сетевых запросов;
- без JavaScript управляющие элементы скрыты, вся исходная таблица доступна.

Контактная заявка и нормативные данные сохранены. Новая библиотека не добавлена.
Один небольшой клиентский компонент добавлен для функционального выбора,
а не оформления. Короткие таблицы не получили лишние элементы выбора.
