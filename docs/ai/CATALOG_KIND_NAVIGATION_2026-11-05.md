Форма принимает только собственный список видов: неизвестный/чужой kind игнорируется. Выбранный вид передаётся с размерами в обычную заявку. Без JavaScript остаются native-ссылки и явный переход в заявку по виду; автоматическое заполнение формы главной требует JavaScript.
