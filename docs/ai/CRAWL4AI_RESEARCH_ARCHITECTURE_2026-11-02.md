# Исследовательский рой «Сайт2»: Crawl4AI и резервные сборщики

Дата: 2026-11-02. Статус: **пилот интеграции, не production**.
Задача: #117; координация #115. Два аккаунта работают с одной `main`; правки изолировать по веткам.

## Архитектурная связка

1. **Очередь задач** — GitHub Issues и существующая матрица `docs/catalog/coverage-2026-11-01/`. Не дублировать завершённые проверки.
2. **Получение публичных страниц** — HTTP для простого статического HTML; [Crawl4AI](https://github.com/unclecode/crawl4ai) для JS и таблиц (после успешного локального PoC); браузерный инструмент только для трудных интерактивных страниц.
3. **Параллельные исследовательские потоки** — трубы; СДТ/изоляция; листы; сортовой/фасонный; цветные; метизы/канаты; UX/заявка. Параллельное чтение допускается; правки по файлам только с раздельным владением.
4. **Нормализация доказательств** — JSON с URL, датой, типом источника, товаром, формой, размером, маркой, стандартом, `verification_status` и `inventory_claim=false`. HTML/Markdown источника не считать подтверждением применимости ГОСТ.
5. **Независимая проверка** — норматив/документация и профильные торговые компании; конфликтующие данные не публиковать.
6. **GitHub PR → CI/preview → review → merge → production QA**. Никакой автоматической публикации результатов сборщика в товарном каталоге.

## Выбор и условие включения

- Основной кандидат: **Crawl4AI** (локальный Python); быстрый резерв — штатный HTTP/HTML.
- Сложный резерв: Browser Use/Playwright, только когда необходим.
- **Установка/PoC не подтверждены.** На Windows доступен Python 3.11; Docker не обнаружен. Попытка `pip install crawl4ai` в отдельном venv столкнулась с TLS `UNEXPECTED_EOF_WHILE_READING`. Не менять глобальные сертификаты и не отключать TLS-верификацию.
- Crawl4AI считать активным только после установки, установки браузера и контрольного извлечения двух публичных страниц. До этого реально работающий fallback — доступные веб/браузерные инструменты, не вымышленный локальный сервис.

## Критерии PoC

- [ ] `import crawl4ai` в изолированном окружении
- [ ] Проверка версии и установки браузера; нет изменений рабочего checkout
- [ ] Два публичных URL металлотрейдеров прочитаны с соблюдением robots/условий
- [ ] JSON содержит точный исходный URL, поля, дату и границы достоверности
- [ ] Сравнение с ручной проверкой 2 страниц; отсутствие выдуманных сочетаний
- [ ] Повторяемый запуск, отчёт, безопасные таймауты и ограничения частоты
- [ ] PR и ревью до перехода в штатную архитектуру

Не расширять количество агентов без полезного независимого задания. Не отправлять заявки и не изменять production в рамках исследования.
