# Безопасное восстановление офлайн-компьютера

## Текущее состояние

- зарегистрированное устройство: `DESKTOP-BNPIVK2`;
- Remote Desktop Commander не выходил на связь с 16 сентября 2026 года;
- облачный коннектор авторизован, но не может выполнить команду, пока локальный Remote Device не запущен;
- зарегистрированная версия была `0.2.50`, актуальная версия проекта — `0.2.51`.

## Первый запуск без изменений Windows

1. На `DESKTOP-BNPIVK2` открыть папку проекта.
2. Дважды щёлкнуть `scripts/start_remote_desktop_commander.cmd`.
3. Оставить открывшееся окно работающим.
4. Если официальный клиент откроет авторизацию, войти в тот же аккаунт Remote Desktop Commander.

Сценарий проверяет Node.js, наличие уже работающего процесса и доступность облачного сервиса. Он запускает только официальную команду:

```powershell
npx --yes @wonderwhy-er/desktop-commander@0.2.51 remote
```

Версия закреплена намеренно. В `0.2.51` вошло исправление сохранения обновлённого refresh token; автоматический переход на будущую версию без отдельной проверки не выполняется.

## Рейтинг способов восстановления

| Приоритет | Способ | Решение сейчас |
|---:|---|---|
| 1 | Запуск Remote Device `0.2.51` с сохранённой сессией | Выбран: минимальное вмешательство и прямое исправление дефекта `0.2.50` |
| 2 | Запуск `0.2.51` с `--debug` | Только если обычный запуск не подключится; даёт диагностику без изменения Windows |
| 3 | Повторная OAuth-авторизация | Только если официальный клиент сам её запросит |
| 4 | Локальный `--logout` и повторная привязка | Не применять первым: удаляет локально сохранённые credentials |
| 5 | Chrome Remote Desktop или RustDesk | Ручной резервный экранный доступ; требует предварительной установки и настройки |
| 6 | MeshCentral | Подходит для постоянного управления несколькими ПК, но добавляет отдельный сервер и агент |
| 7 | Tailscale + Windows RDP/OpenSSH | Хороший приватный сетевой канал, но требует включения системных компонентов Windows |
| 8 | OpenAI Secure MCP Tunnel | Лучший отдельный канал для Obsidian API, но не запускает остановленный ПК или приложение |
| 9 | Cloudflare Tunnel | Только резерв для конкретного локального веб-сервиса; не заменяет удалённый терминал |
| 10 | Wake-on-LAN | Нужен лишь если компьютер выключен/спит; требует BIOS/UEFI и сетевого устройства, поэтому сейчас не трогаем |

Автозапуск через Task Scheduler, службу Windows или сторонний watchdog возможен, но сознательно отложен: сначала нужен один успешный обычный запуск и анализ журналов.

## Что сценарий принципиально не делает

- не требует прав администратора;
- не изменяет реестр и службы Windows;
- не изменяет firewall, антивирус, сеть, VPN и DNS;
- не отключает сон или гибернацию;
- не создаёт задания планировщика и элементы автозагрузки;
- не удаляет старую конфигурацию и сохранённую OAuth-сессию;
- не запускает второй экземпляр, если Remote Device уже найден.

## Другие способы доступа

| Вариант | Назначение | Ограничение |
|---|---|---|
| Remote Desktop Commander | Файлы, терминал и процессы из ChatGPT | Локальный Remote Device должен работать |
| OpenAI Secure MCP Tunnel | Obsidian Local REST API и другие локальные MCP | Windows, Obsidian и tunnel-client должны работать |
| Общий проект ChatGPT | Общий контекст Anthony Roberts и Do Quoc An | Не даёт доступ к Windows |
| Chrome Remote Desktop | Ручное управление экраном | Требует заранее включённого удалённого доступа |
| Playwright MCP | Раздельные браузерные профили двух аккаунтов | Локальный мост должен работать; не заменяет доступ к ОС |
| Cloudflare Tunnel | Резерв для локального веб-сервиса | Сложнее; нужен строгий контроль доступа |

## После восстановления связи

1. Подтвердить в ChatGPT, что `DESKTOP-BNPIVK2` online.
2. Прочитать локальные журналы Desktop Commander без их очистки.
3. Проверить Obsidian API и выполнить подготовленную синхронизацию.
4. Если обычный запуск не подключился, выполнить безопасную диагностику:

   ```powershell
   npx --yes @wonderwhy-er/desktop-commander@0.2.51 remote --debug
   ```

5. Только после устойчивого теста отдельно решить вопрос автозапуска. До этого системные настройки Windows не менять.
