## Рабочий запуск

Для анализа последней завершенной недели, исключая визиты, распознанные
Метрикой как роботы:

```bash
NODE_USE_ENV_PROXY=1 node scripts/metrika-report.mjs --counter 113661397 --days 7 --exclude-robots --out /workspace/.cloud/magic-metal/analytics/report-week-nonrobots.json
```

Для контрольного общего отчета убрать `--exclude-robots`. Даты определяются
API в часовом поясе счетчика, незавершенный сегодняшний день не включается.
Результат содержит текущий и равный предыдущий периоды, источники, устройства,
посадочные пути без query/fragment и зарегистрированные цели.

Фильтр `ym:s:isRobot=='no'` применяется одинаково ко всем статистическим
запросам, включая цели обоих периодов. Состояние фильтрации самого счетчика
не меняется. Метка «не робот» не гарантирует живого покупателя и не исключает
все QA-визиты; единственное тестовое событие не считать коммерческой заявкой.
Цели — отдельные агрегаты, не доказанная последовательная воронка.
Автоцель отправки формы и `request_sent` нельзя суммировать.
