# Конкурентный аудит MagicMetal — 2026-11-02

## Статус и метод
Первичный аудит публичных страниц; Firecrawl live fetch для mkm-metal.ru, g-nova.ru/catalog и magicmet.ru. LKMET просмотрен по поисковому индексу (попытка live-fetch завершилась DNS-ошибкой); для Stalonline, 74MET и других имеются сведения из результатов поиска. Ниже указаны наблюдения и гипотезы, не факт работы каждой функции в браузере.

## Проверенные образцы
1. **Металлокомплект-М** https://mkm-metal.ru/ — каталог ведёт на shop.mkm-metal.ru; отдельные услуги по резке, рубке, размотке, упаковке, доставке, есть раздел ГОСТ и ссылка на быстрый заказ. Источник: live Firecrawl.
2. **Джинова** https://g-nova.ru/catalog — подробная разбивка по типу проката; поиск по типу/марке/размеру; заявка с чертежом/файлом. Источник: live Firecrawl.
3. **LKMET** https://lkmet.ru/ — по результатам поиска заявлены фильтры город, категория, размер, ГОСТ, длина, марка; мобильные карточки вместо широкой таблицы. Live-fetch не состоялся, проверить в браузере.
4. **СтальРадар** https://stalonline.ru/ — по индексируемому описанию строит смету из текстовой спецификации и проверяет сомнительные строки отдельно; проверить фактическое поведение.
5. **74MET** https://74met.ru/ — по индексируемому описанию сравнение предложений и запрос цены, без утверждения, что данные актуальны на момент покупки.
6. **Собственный сайт** https://magicmet.ru/ — live Firecrawl показал каталог, поиск, калькулятор, справочник ГОСТ и общий CTA «Отправить готовую заявку» с Excel/PDF/чертежом/фото.

## Приоритеты для Сайт1
P0 — **Единый поиск** по изделию, марке (М1, Л63, БрАЖ9-4, 09Г2С, A500C), ГОСТ, размеру и распространённым вариантам написания. Проверить корректность выдачи и наличие прямого пути к заявке; не создавать ложных фактов наличия.
P0 — **Заявка по спецификации**: принимать список строк и файл, разбивать строки на изделия, марки, размер, ГОСТ/ТУ и количество; неоднозначные строки явно помечать «нужна проверка», не угадывать.
P1 — **Единый шаблон карточки**: вид товара, обозначение и возможные марки, нормативная ссылка, геометрия или спецификация состава, форма поставки, заявление о необходимости подтверждения наличия и цены, CTA с заполненными атрибутами.
P1 — **Мобильный каталог**: адаптивные карточки с понятными подписями вместо горизонтально прокручиваемой таблицы; 320px и 200% zoom QA.
P1 — **Услуги**: резка, комплектация, упаковка, документы, доставка, где реально доступны, без неподтверждённых обещаний.
P2 — **Смета** по многопозиционной заявке с теоретической массой только по верифицированным размерным таблицам; отдельно расчёт доставки.

## Ограничения и критерии приёмки
Нельзя копировать чужие тексты/дизайн и заявлять непроверенные цены, остатки или сертификаты. Перед реализацией сравнить с текущим main, задачами другого аккаунта и PR #114; не править dirty checkout.
Критерии: поиск находит соответствующую позицию по марке/ГОСТ и правильно обрабатывает отсутствие; файл и текст заявки сохраняют все исходные строки; карточки мобильны, клавиатурно доступны; производственный сайт не меняется до review; функциональные тесты проверяют маршрут заявки без отправки реальной заявки.
