# Phase 12 — Knowledge Loop

## Цель
Сохранять несколько фактов после завершённой закупки, чтобы использовать их дальше.

## Сохраняем
- товар;
- поставщик — только во внутреннем слое;
- фактическую закупочную цену — только во внутреннем слое;
- фактический срок;
- результат: успех / неуспех;
- дату записи.

## Принцип
Не строим отдельную AI-систему обучения. Knowledge Loop — это простая фиксация фактических результатов закупок.

Реализация: `src/lib/agents/knowledgeLoop.ts`.
