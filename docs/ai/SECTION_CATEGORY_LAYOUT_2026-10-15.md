# Раздел сортового и фасонного проката: компактный каталог

Вариант одобрен пользователем 15.10.2026. Изменён только маршрут
`/produkciya/sortovoy-i-fasonny-prokat`; остальные категории сохраняют
существующий компонент. Новый `SectionCatalog` — серверный компонент.

Сразу после краткого вступления — шесть конкретных видов продукции,
размеры/исполнение и стандарты их проверенных таблиц. Две обзорные
страницы сохранены отдельными ссылками после списка. Поясняющий текст,
марки и справочник материалов расположены ниже выбора товара.
На широком экране заявка находится справа, на планшете и телефоне —
под списком. Вся строка товара — обычная ссылка, работающая без JavaScript.
Корзина, аналитика, лид-магниты и новые клиентские модули не добавляются.

на телефоне 28/34; h2 22/28; товар 18/24; вступление 16/24,

Белый фон, светлые чередующиеся строки и существующие фирменные цвета.
Правила CSS ограничены классами нового раздела и учитывают приоритет
глобальной начальной и отложенной типографики.

## Проверка до публикации

69 профильных тестов прошли, один необязательный тест закрытого снимка
поставщика пропущен. Линтер и production-сборка `next build --webpack`
прошли. Публичный режим сборки по-прежнему не проверяет все типы проекта.
Первый тест обнаружил необходимость обновить статические ссылки главной
для новых таблиц нержавеющих труб; каталог пересоздан штатным скриптом,
после этого профильные тесты прошли. Проверки не отключались.

Браузер без JavaScript: 320, 390, 768, 1536 px. Проверены шесть строк,
две обзорные ссылки, размеры/ГОСТы, переход к карточке круга с 101
размером, контекст заявки, отсутствие переполнения и обрезанных стрелок.
Просмотрены desktop/mobile и планшетный экран; для планшета боковой блок
перенесён вниз, чтобы названия помещались в колонку.

На 390 px список начинается на 329 px от верха документа. В исходном
варианте даже начало раздела с выбором товара находилось на 1209 px.
При искусственной задержке `site.css` размер, вес и высота h1,
координата и ширина списка совпадают до и после загрузки CSS на 390
и 1536 px. Проверка повторена на окончательной сборке.

Главная сохраняет весь HTML вне каталога побайтово; изменены только две
ссылки на новые размерные таблицы. HTML gzip 12043 → 12046 байт,
один скрипт. Локальные payload и геометрия:
`/workspace/.cloud/magic-metal/section-category-review-2026-10-15/`.
