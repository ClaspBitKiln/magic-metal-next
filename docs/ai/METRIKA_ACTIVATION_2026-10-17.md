# Подключение счётчика 113661397

Владелец создал счётчик magicmet.ru и подтвердил его номер снимками кабинета.
В настройках видны ограничение доменом magicmet.ru и GMT+05 Екатеринбург.

Общий серверный getMetrikaCounterId подключает этот публичный ID в статическую
главную и страницы каталога/справочников. ID сохранён в коде, поэтому не
пропадёт при смене облачной среды. NEXT_PUBLIC_YANDEX_METRIKA_ID позволяет
переопределить ID; 0 отключает подключение после пересборки. OAuth-ключей
в коде или браузере нет. Вебвизор, карты кликов и автоматическое отслеживание
ссылок в SDK выключены; собственные события передают только имена действий.

Проверки: 3 профильных теста прошли; полный ESLint и production-сборка прошли.
Браузер с подставным SDK проверил реальную конфигурацию ID без инъекции
счётчика, один init на документ и SPA-переход с дополнительным pageview без
повторного init. Подставные ошибка, сохранённая заявка и honeypot подтверждают
отсутствие ложных целей; файл после ошибки сохранён. Реальных POST заявок и
писем не было; данные не отправлялись в чужой счётчик.

52 маршрута проверены по ресурсам. Главная: HTML gzip 12116 байт (до активации
12082), 2 локальных скрипта (вместо 1), вместе 2741 байт gzip (вместо 1331).
Это объём локального кода; SDK Яндекса загружается отдельно после load/idle.

Один мобильный Lighthouse 13.5.0 готовой локальной production-сборки: score99,
LCP1813мс, CLS0, TBT82мс. Исходный отчёт сохранён, улучшением это не называется.
Его нельзя напрямую сопоставлять с прежним статическим зеркалом: другой
способ HTTP-доставки. Запрос SDK был блокирован облачным сетевым прокси;
повтор с разрешённым выходом тоже отклонён (403). Поэтому полное влияние
SDK на скорость и получение данных Метрикой из облака не подтверждены.
После публикации владелец проверяет счётчик из своего браузера.

Настройка action-goals в кабинете и авторизованный API-доступ к отчётам —
отдельные незавершённые шаги. Наличие счётчика и отправка reachGoal сами по
себе не доказывают, что эти цели созданы или что отчёты уже доступны агенту.
Программа их автоматического создания подготовлена, но без OAuth не запускалась.
