# Magic Metal — упрощение CTA каталога

## Решение

- Убраны десять повторяющихся кнопок «Заявка» в карточках каталога.
- Каждая карточка раздела стала одной доступной ссылкой на форму с выбранным направлением.
- В шапке каталога оставлена одна общая кнопка «Отправить заявку».
- В форме показывается выбранный раздел.
- Текст формы уточняет самовывоз или доставку с городом и согласование возможной замены.
- Первый шаг формы упрощён: удалены повторные заголовки и постоянное сообщение об отсутствии файлов; оставлены одно действие загрузки, краткая подсказка, описание и продолжение.
- Мобильная шапка упрощена: на ширине до 480 px CTA сокращается до «Заявка», язык и меню имеют области нажатия минимум 44×44 px.
- Второй шаг формы сокращён до телефона, email, согласия и кнопок; имя, компания и повторный выбор направления удалены.
- Сквозной тест обнаружил `500` из-за обязательной зависимости маршрута от Payload/Postgres; сохранение, SMTP и CRM разделены на независимые каналы с явным `503`, только если не сработал ни один канал.
- Повторный тест локализовал корневую причину: статический импорт `payload.config` проверял `PAYLOAD_SECRET` и `DATABASE_URL` до запуска обработчика. Конфигурация Payload переведена на динамический импорт внутри защищённого канала сохранения; обработчики ошибок SMTP/CRM больше не зависят от недоступного `payload.logger`.
- Удалён жёстко записанный URL-токен Activepieces; интеграция теперь использует только защищённые переменные `N8N_WEBHOOK_URL` или `CRM_WEBHOOK_URL` в Vercel.
- Из полосы доставки удалён третий дублирующий CTA первого экрана.
- Добавлены видимые состояния клавиатурного фокуса для карточек и загрузки файла.

## Проверки

- `npm run lint` — успешно.
- `npm run build` — успешно, 140 статических страниц сформированы.
- Общий `tsc --noEmit` по-прежнему находит ранее существовавшие ошибки закупочного контура; изменённые файлы новых ошибок сборки не создают.
