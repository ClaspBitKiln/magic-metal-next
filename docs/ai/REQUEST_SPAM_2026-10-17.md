# Защита формы от двух наблюдавшихся типов спама

Публикация: `d8eb09f`, Vercel success, 17.10.2026.

Серверный фильтр перед сохранением, SMTP и CRM отклоняет:

- рекламный текст, в котором одновременно есть backlink/link building,
  SEO/WordPress, предложение аудита/скидки, unsubscribe и внешняя ссылка;
- два длинных одиночных латинских токена с частой сменой регистра в запросе
  и получении, только если нет имени, компании, контекста, направления и файлов.

Это узкие эвристики, а не обещание остановить весь спам. Английский язык,
внешняя ссылка или отсутствие имени сами по себе не являются основанием отказа.
Капча, дополнительные браузерные зависимости и обязательные поля не добавлены.
Персональные данные присланных примеров в тесты не включены.

Проверки: 28 тестов в трёх файлах request-spam, request-spam-api,
request-consent; полный ESLint; production build с SIMPLE_PUBLIC_SITE_BUILD=1.
Эта сборка не подтверждает устранение прежних ошибок полного TypeScript.
API-тесты подменяют хранилище, SMTP и fetch и подтверждают отсутствие вызовов
при отказе. Реальные письма, CRM-запросы и production POST не выполнялись.

До/после на главной: HTTP 200, 59 625 байт HTML, 12 056 байт Node gzip,
один script, форма request присутствует. Локальная production-версия совпала.
Замеры размера не являются измерением LCP/INP. Серверный фильтр не меняет HTML.
Артефакты: `/workspace/.cloud/magic-metal/spam-review-2026-10-17/`.
