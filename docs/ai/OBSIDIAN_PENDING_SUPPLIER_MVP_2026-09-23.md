# Magic Metal — простой MVP поиска поставщиков

## Решение

- Старый PR №16 не возобновляется целиком: его проверенный вертикальный срез перенесён в свежую ветку от текущего `main`.
- Поток менеджера сокращён до двух шагов: заявка → поиск и выбор.
- КП, маржа, распределение объёма и автоматическая отправка клиенту исключены.
- Поиск принимает несколько строк заявки, нормализует товар, размер, марку, стандарт и количество.
- Metalinfo-предложения проходят строгую проверку идентичности и свежести доказательства.
- Менеджер вручную подтверждает цену с НДС, доступный объём, расходы на партию и источник проверки.
- Победителем становится только готовый к исполнению вариант с минимальной подтверждённой полной стоимостью.
- Если `FIRECRAWL_API_KEY` отсутствует, интерфейс явно показывает тестовый режим с демонстрационными предложениями.

## Проверки

- 36 из 36 профильных тестов прошли.
- `npm run lint` — успешно.
- `npm run build` — успешно; 142 страницы, включая `/rfq-workbench` и API поиска.
- Vercel Preview — `READY`, доступ защищён Vercel SSO.

## Публикация

- Черновой PR №31: `codex/supplier-search-mvp-20260923`.
- В production не сливать до проверки доступа менеджера и живого Firecrawl-поиска.

## Следующий тест

1. Ввести одну позицию трубы.
2. Получить точные предложения.
3. Подтвердить цену, наличие и расходы.
4. Проверить выбор минимальной полной стоимости.
5. Если точных предложений нет — перейти к импорту реального XLSX/CSV прайса.
