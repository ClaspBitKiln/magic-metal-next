# Каталог, таблицы и подключения — 14 октября 2026

Заметка подготовлена в технической копии проекта для Obsidian. Действующий
Obsidian Gateway и локальное хранилище в облачной среде не обнаружены;
фактическая запись в пользовательский vault пока не подтверждена.
Существующая архитектура описана в `OBSIDIAN_SYNC_ARCHITECTURE.md`.
Ключи, пароли и содержимое документа с доступами сюда не переносятся.

## Решения пользователя

- Примеры брать у российских сайтов металлопроката.
- Оформить существующие таблицы красиво и удобно, без тяжёлых библиотек.
- Приоритет — скорость загрузки и работа сайта; заявки доступны напрямую.
- Размеры проверять по ГОСТ. Актуальные остатки сейчас не рассматриваются.
- Публичные ссылки на источники в интерфейс не добавлять.
- Использовать Firecrawl при необходимости и записать результаты в Obsidian.

## Что действительно удалось проверить

**Metal100:** страницы трубного проката и холоднодеформированных труб отвечают
HTTP 200. Проверены браузером на 1536 и 390 px. Есть раздел «Выберите размер»,
короткие ссылки D×s, группировка по виду продукции, явные единицы измерения
и светлое чередование строк. На мобильном экране часть широких таблиц выходит
за границы; заимствуется группировка и компактная запись, а не фиксированная ширина.

**23met:** получены публичные HTTP 200 HTML страниц балки и горячекатаного
листа/рулона, а также официальный CSS. В HTML есть отдельные переходы
«Размеры» и «ГОСТы и ТУ». Последующие обращения браузера и Firecrawl получили
ограничение частоты запросов; Firecrawl указал исходный HTTP 429. Экран защиты
не считается осмотренной товарной таблицей. Капча не решалась, повторные обходные
запросы для её преодоления не выполнялись.

**Металлсервис:** каталог ответил HTTP 503. **ЕВРАЗ:** прайс ответил HTTP 403.
Их современное оформление не объявляется проверенным.

Цены и остатки из внешних каталогов не перенесены в нормативные таблицы.

В черновик сети добавлены домены российских каталогов и `api.firecrawl.dev`
с сохранением прежних адресов. Сохранение черновика и фактический доступ
проверяются отдельно. Firecrawl не добавляется в браузерный JavaScript сайта.

Через Firecrawl также успешно получена публичная страница холоднодеформированных
труб Metal100: запрос сервиса HTTP 200 / success=true, исходная страница HTTP 200.
Это подтверждает работоспособность REST API; результат ограничения 23met
не интерпретируется как ошибка ключа.

## Выбранное улучшение

1. Быстрый выбор таблиц и типов балки перед первым размерным рядом — обычные
   ссылки к содержимому штатных `details`, без нового клиентского JavaScript.
2. Заголовок исполнения и компактная метка ГОСТ имеют разные уровни оформления.
   Полная подпись таблицы сохраняется для программ чтения с экрана.
3. Первая расшифровка или ограничение показывается перед таблицей. Остальные
   примечания и все нормативные значения сохраняются.
4. Перечни размеров не разрываются внутри десятичных значений; списки имеют
   немного больше воздуха. Каждое число не превращается в отдельный DOM-элемент,
   чтобы не раздувать таблицы с тысячами сочетаний.
5. Сохраняются светлые строки, закреплённые шапка и первый столбец,
   выравнивание одиночных чисел вправо и обычная заявка.

  балка: 39716 → 40247 байт в локальной production-сборке. Новых скриптов нет.
  Это контроль объёма, а не измерение времени загрузки у посетителей.

Код опубликован в `main`, коммит `c53d71a`, Vercel подтвердил успешное

адрес шлюза не предоставлен, запись в пользовательский vault не подтверждена.

## Найденная прежняя настройка Obsidian

По просьбе пользователя проверены репозитории GitHub и прежние ветки.
В ветке `codex/obsidian-account-bridge-20260922` найден
`scripts/sync_obsidian.mjs`: он использует Obsidian Local REST API,
`OBSIDIAN_API_URL` и `OBSIDIAN_API_KEY`, записывает отдельную заметку
через `/vault/…` и проверяет её повторным чтением и SHA-256.
Адрес по умолчанию — `https://127.0.0.1:27124` на компьютере с Obsidian;
это не адрес пользовательского компьютера из облачной среды.

В PR #20 от 22 сентября фактическая запись ожидала восстановления связи
с `DESKTOP-BNPIVK2`. Это исторический статус; нынешнее состояние этого ПК
не проверено. В текущей сессии нет коннектора Remote Desktop Commander,
Obsidian API или переменных его подключения. Локальные порты 27123 и
27124 облачной среды недоступны. GitHub не разрешил чтение метаданных
Actions variables/secrets (HTTP 403), поэтому их наличие не установлено.

В приватном `inn-bot` также найдено зеркало `collab/obsidian_mirror/`:
`SYNC_MEMORY.bat` копирует заметки с Windows в GitHub. Обратная запись
из GitHub в Obsidian этим сценарием не выполняется.

Для завершения нужен доступ к прежнему локальному подключению либо
действующий адрес уже настроенного шлюза и секрет через защищённую
конфигурацию среды. Секреты в заметку и Git не добавлялись.
