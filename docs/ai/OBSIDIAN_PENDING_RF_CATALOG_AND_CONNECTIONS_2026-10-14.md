# Каталог, таблицы и подключения — 14 октября 2026

14 октября пользователь запустил Windows-программу синхронизации.
На присланном скриншоте программа подтверждает запись и проверку заметки
в хранилище `inn-bot`, а также установку обновления при входе в Windows.
Повторный вход в Windows пока не проверен. Облачное REST/MCP-подключение
к этому хранилищу по-прежнему не настроено; программа записывает Markdown
непосредственно в локальное хранилище.
Существующая архитектура описана в `OBSIDIAN_SYNC_ARCHITECTURE.md`.
Ключи, пароли и содержимое документа с доступами сюда не переносятся.

## Решения пользователя

- Примеры брать у российских сайтов металлопроката.
- Оформить существующие таблицы красиво и удобно, без тяжёлых библиотек.
- Приоритет — скорость загрузки и работа сайта; заявки доступны напрямую.
- Размеры проверять по ГОСТ. Актуальные остатки сейчас не рассматриваются.
- Публичные ссылки на источники в интерфейс не добавлять.
- Использовать Firecrawl при необходимости и записать результаты в Obsidian.

## Что действительно удалось проверить

**Metal100:** страницы трубного проката и холоднодеформированных труб отвечают
HTTP 200. Проверены браузером на 1536 и 390 px. Есть раздел «Выберите размер»,
короткие ссылки D×s, группировка по виду продукции, явные единицы измерения
и светлое чередование строк. На мобильном экране часть широких таблиц выходит
за границы; заимствуется группировка и компактная запись, а не фиксированная ширина.

**23met:** получены публичные HTTP 200 HTML страниц балки и горячекатаного
листа/рулона, а также официальный CSS. В HTML есть отдельные переходы
«Размеры» и «ГОСТы и ТУ». Последующие обращения браузера и Firecrawl получили
ограничение частоты запросов; Firecrawl указал исходный HTTP 429. Экран защиты
не считается осмотренной товарной таблицей. Капча не решалась, повторные обходные
запросы для её преодоления не выполнялись.

**Металлсервис:** каталог ответил HTTP 503. **ЕВРАЗ:** прайс ответил HTTP 403.
Их современное оформление не объявляется проверенным.

Цены и остатки из внешних каталогов не перенесены в нормативные таблицы.

не интерпретируется как ошибка ключа.

## Выбранное улучшение

1. Быстрый выбор таблиц и типов балки перед первым размерным рядом — обычные
   ссылки к содержимому штатных `details`, без нового клиентского JavaScript.
2. Заголовок исполнения и компактная метка ГОСТ имеют разные уровни оформления.
   Полная подпись таблицы сохраняется для программ чтения с экрана.
3. Первая расшифровка или ограничение показывается перед таблицей. Остальные
   примечания и все нормативные значения сохраняются.
4. Перечни размеров не разрываются внутри десятичных значений; списки имеют
   немного больше воздуха. Каждое число не превращается в отдельный DOM-элемент,
   чтобы не раздувать таблицы с тысячами сочетаний.
5. Сохраняются светлые строки, закреплённые шапка и первый столбец,
   выравнивание одиночных чисел вправо и обычная заявка.

## Найденная прежняя настройка Obsidian

По просьбе пользователя проверены репозитории GitHub и прежние ветки.
В ветке `codex/obsidian-account-bridge-20260922` найден
`scripts/sync_obsidian.mjs`: он использует Obsidian Local REST API,
`OBSIDIAN_API_URL` и `OBSIDIAN_API_KEY`, записывает отдельную заметку
через `/vault/…` и проверяет её повторным чтением и SHA-256.
Адрес по умолчанию — `https://127.0.0.1:27124` на компьютере с Obsidian;
это не адрес пользовательского компьютера из облачной среды.

В PR #20 от 22 сентября фактическая запись ожидала восстановления связи
с `DESKTOP-BNPIVK2`. Это исторический статус; нынешнее состояние этого ПК
не проверено. В текущей сессии нет коннектора Remote Desktop Commander,
Obsidian API или переменных его подключения. Локальные порты 27123 и
27124 облачной среды недоступны. GitHub не разрешил чтение метаданных
Actions variables/secrets (HTTP 403), поэтому их наличие не установлено.

В приватном `inn-bot` также найдено зеркало `collab/obsidian_mirror/`:
`SYNC_MEMORY.bat` копирует заметки с Windows в GitHub. Обратная запись
из GitHub в Obsidian этим сценарием не выполняется.

Для облачного REST/MCP-подключения нужен доступ к прежнему локальному
подключению либо действующий адрес шлюза и секрет через защищённую
конфигурацию среды. Для локальной программы синхронизации шлюз не требуется.
Секреты в заметку и Git не добавлялись.

### Восстановление инструмента в текущей ветке

`scripts/sync_obsidian.mjs` восстановлен отдельно от кода сайта.
Скрипт создаёт подготовленную заметку и проверяет содержимое повторным
чтением. Повторный запуск не создаёт дублей, существующая заметка с другими
данными не перезаписывается. Проверка TLS сохранена, добавлен таймаут запросов.
Новые зависимости и клиентские скрипты сайта не добавлялись.

Прошли 7 профильных API-тестов на локальном тестовом сервере, полный lint
и production-сборка в принятом режиме публичного сайта. Запуск команды
без пользовательского ключа корректно завершается с ошибкой
`OBSIDIAN_API_KEY is required`; реальный vault этим запуском не затрагивался.

В черновике облачной среды сохранены требование `OBSIDIAN_API_URL` и
инструкция повторного запуска. Это не применяет настройки автоматически:
требуется сохранить настройки и опубликовать среду. Требование proxy-секрета
для API-ключа следует добавить после получения действующего имени шлюза,
чтобы ограничить передачу ключа именно его HTTPS-адресом.

## Успешный запуск программы на Windows

Пользователь скачал `docs/downloads/Obsidian-AutoSync.zip`, распаковал его
и запустил `START.cmd`. На скриншоте видны сообщения «Заметка сохранена
и проверена в Obsidian» и «Автоматическое обновление включено при входе
в Windows». Это подтверждение результата программы на ПК пользователя;
удалённого доступа к его диску у облачного агента нет.

Заметка находится в `inn-bot/Мэджик Металл/Синхронизация из GitHub/`.
Программа получает только публичную заметку из GitHub, сохраняет её локально
и проверяет содержимое. Пользовательские изменения не перезаписываются.
Автозапуск установлен только для текущего пользователя. Шлюз, API-ключ,
изменение firewall или открытие портов не требуются.

До передачи программы выполнены 11 тестов настоящим PowerShell в облачной
среде: поиск хранилища, запись, повторный запуск, обновление, сохранение
правок, ошибки источника и реальное скачивание по HTTPS. После передачи
первый запуск на Windows подтверждён скриншотом. Следующая проверка —
обновление этой заметки после повторного входа в Windows.

Для облачных инструментов сохранён отдельный загрузчик настроек и черновик
постоянной конфигурации среды. Прошли 4 теста загрузчика; повторные проверки
GitHub и Firecrawl успешны. Публикация обновлённой облачной среды и
восстановление её настроек в новой сессии пока не подтверждены.

## Сайт: завершение переходов и справочника ГОСТ

Obsidian отложен по указанию пользователя; приоритет снова у сайта.
Для размеров и нормативных данных используются стандарты, действующие
в России, и российские первичные нормативные источники.

В обзорных карточках «Круг и квадрат» и «Фасонный прокат» добавлены пять
прямых переходов к уже проверенным размерным таблицам. Таблицы в обзорных
карточках не дублируются; использованы существующие стили и обычные ссылки.

Справочник ГОСТ теперь использует те же проверенные таблицы, что и карточки
продукции. Старые рыночные сигналы, пометки наличия и дата их обновления
удалены. Для стандартов без опубликованной таблицы оставлено пояснение
о спецификации и прямая заявка с кодом ГОСТ.

ГОСТ 30245-2003 подтверждён по карточке Росстандарта как действующий в РФ;
добавлена его карточка в справочник. Замена на редакцию 2012 года без проверки
была бы ошибкой: введение этой редакции в РФ отменено. Перед заполнением
строительных профилей отдельно проверяются таблицы и поправка ИУС № 5-2021.

Готовая часть проверена: 62 профильных теста прошли, один необязательный тест
приватного снимка поставщика пропущен; полный lint и production-сборка
успешны. Пять переходов проверены реальными кликами без JavaScript на
320, 390 и 1536 px. В справочнике проверены таблицы на 390 и 1536 px и
перенос ГОСТ в обычную заявку; реальные заявки не отправлялись.
Локальный размер главной страницы сохранился: 12035 байт gzip, один скрипт.

Основная матрица холоднодеформированных труб ГОСТ 8734-75 и таблицы
строительных профилей ГОСТ 30245-2003 проверяются отдельными агентами.
В этой опубликованной части они ещё не добавлены; непроверенные размеры
не выдаются за нормативные.
