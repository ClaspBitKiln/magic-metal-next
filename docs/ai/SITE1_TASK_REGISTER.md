## Работа двух аккаунтов

- Эта пачка: рельсы, канаты, согласованность каталога и диагностика Desktop.
- Во втором аккаунте по новым коммитам `a6f55b5..adc9ed7` выполнены Метрика
  и исправления QA. Не повторять их и не перезаписывать текущими старыми отчётами.
- Изменения готовить в отдельной ветке. Перед объединением сверять удалённый
  main и пересечения файлов; сохранять обе стороны. Не использовать reset/force-push.
- Общие MEMORY и центр знаний объединять по содержанию, а не заменять целиком.
- Проверять только затронутые сценарии; широкие проверки перед публикацией
  выполнять один раз для итоговой объединённой версии.
- Статус доступа в одной среде не переносить на другую. Метрика восстановлена
  во второй сессии; запрос нового токена из этой пачки не требуется.
