# Возвращение magicmet.ru на SpaceWeb: проверенные факты23.11.2026

## История

Старый сайт был WordPress на SpaceWeb, исторический IP77.222.62.219. По записи `OBSIDIAN_PENDING_DOMAIN_CUTOVER_2026-09-28.md` домен переключили на Vercel28.09.2026; старый WordPress сохраняли для временного отката. Это не доказательство, что старый тариф или резерв сегодня активны. DNS тогда обслуживал SpaceWeb, почтовые MX/SPF/DKIM/DMARC не менялись.

Владелец сообщил, что Beget сломан после хакерской атаки. Этот сервер не является готовым резервом сайта. Восстановление Beget/inn-bot не начиналось, никаких переноса/переустановки там нет.

## Совместимость

Нынешний код использует Next.js16.3, Node.js и серверную обработку заявок. Официальная справка SpaceWeb https://help.sweb.ru/dopolnitel6noe-po-na-serverah-virtual6nogo-hostinga_1208.html (последнее обновление17.09.2025, полученаHTTP200 23.11.2026) прямо говорит: на Node.js нельзя запустить веб-приложение на обычном виртуальном хостинге, для полноценной работы рекомендуетсяVDS.

SpaceWeb предлагает VDS с Node.js: https://sweb.ru/vds/nodejs/ (HTTP20023.11). Это технически подходящий класс услуги, но не бесплатная замена и не подтверждённый уже оплаченный тариф владельца. Состояние аккаунта, ресурсные требования сайта и стоимость нужной конфигурации не проверены. Рекомендация SpaceWeb2GB для общего Node-решения не является измеренным требованием нашей Next-сборки.

## Безопасный порядок, если перенос будет выбран

1. Проверить действующий аккаунт/тариф SpaceWeb и резерв старого сайта без измененияDNS.
2. Подготовить отдельныйVDS/технический домен, совместимыйNode и production-конфигурацию из правильной ветки. Не брать старый dirtyCMScheckout и не считать готовыйDockerfile автоматически рабочим.
3. Проверить страницы каталога, языки/ссылки, HTTPS, форму с вложениями, доставку письма и Метрику. Конфиденциальные переменные перенести защищённо.
4. Сделать резерв и контролируемое переключение только webDNS. Почту Яндекса и еёMX/TXT не менять. Сохранить возможность отката.
5. Отключать Vercel только после подтверждения работы нового размещения.

На этом этапе ничего не покупалось и не переносилось. Vercel, тарифы, DNS и серверы не изменены. Вопрос владельца о возможности возвращения не трактуется как разрешение отключить рабочий хостинг до готовой замены.
