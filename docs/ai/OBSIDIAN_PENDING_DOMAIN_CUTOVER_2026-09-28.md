# Magic Metal — переключение домена на Vercel

## Решение

Простой публичный сайт `magic-metal-next` публикуется на основном домене `magicmet.ru`. Старый WordPress на SpaceWeb сохранён как временный резерв и не удаляется минимум 48 часов.

## Резерв до переключения

- Архив старого сайта: `magicmet-old-site-backup-2026-09-27.zip`.
- SHA-256: `a7f35d4a73cbc612713f80bf3610b47602397cbe8468b7bd1dccf333b9922a64`.
- Снимок DNS сохранён отдельно перед изменением.
- Откат apex: вернуть `A @ → 77.222.62.219`.
- Откат www: вернуть `A www → 77.222.62.219`.

## Изменения DNS

Выполнено через официальный SpaceWeb API 2026-09-28 около 11:50 UTC:

- `A @ → 216.198.79.1`.
- `CNAME www → 996d484916a38720.vercel-dns-017.com.`.
- NS не менялись.
- MX Яндекс.Почты не менялся: `10 mx.yandex.net.`.
- SPF, DKIM, DMARC и записи подтверждения Яндекс/Google не менялись.

## Проверка

- SpaceWeb API повторно вернул новые A/CNAME.
- Google DNS уже видит новый apex; `www` распространяется между резолверами в пределах TTL.
- HTTP для apex и www отвечает новым сайтом с заголовком `Server: Vercel`.
- Главная страница возвращает 200 и содержит утверждённый простой интерфейс и кнопку «Отправить заявку».
- Preview `magic-metal-next.vercel.app` возвращает 200.
- HTTPS-сертификат Vercel находится в автоматическом выпуске после смены DNS; повторная проверка обязательна перед окончательным закрытием этапа.

## Не трогать

- Яндекс.Почту и все почтовые DNS-записи.
- Старый SpaceWeb-хостинг до подтверждения HTTPS и завершения окна отката.
- Закупочный MVP и КП — отдельные следующие этапы.
