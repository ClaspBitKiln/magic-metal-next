## Замечание для следующего оператора

У Glotr обнаружено автокопирование русского текста в узбекское поле при последующих изменениях русского названия. Перед Save нужно завершить RU-название, затем **последним** нативно заполнить UZ-описание, вызвать обычное изменение редактора/blur и проверить, что тексты действительно различаются. Для TinyMCE одного видимого текста без события ввода недостаточно: использовались нативный ввод, Space/Backspace, blur, `save`/`change`. После сохранения — один свежий GET, а не повторная отправка формы.

В этой пачке новых дублей не создано. Другие сайты, исходящие письма и расписания не менялись. Следующий шаг — проверить результат модерации при следующем рабочем заходе и путь с опубликованных объявлений до заявки; не заполнять лимит 100 ради количества.
