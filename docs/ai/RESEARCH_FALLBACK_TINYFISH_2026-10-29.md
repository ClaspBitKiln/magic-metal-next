# Замена Firecrawl и восстановление исследований каталога

Дата: 2026-10-29. Статус: **локальный бесплатный резерв работает**; TinyFish установлен, но инструменты TinyFish не доступны в текущем наборе команд ChatGPT.

## Подключения

- Firecrawl: на момент проверки 0 кредитов; новые агентные задания не запускаются.
- TinyFish: установлен в ChatGPT, подтверждено каталогом подключений; в активном сеансе **нет доступных вызываемых инструментов TinyFish**. Не утверждать, что через него уже проведено исследование.
- Резерв: Windows `DESKTOP-BNPIVK2`, Node.js, без API-ключей и расходов за Firecrawl. Скрипт `scripts/research/competitor-fetch.cjs`. Локальная рабочая копия `%LOCALAPPDATA%\MagicMetalObsidianSync\competitor-fetch.cjs`.

## Проверено реально

- `https://base.garant.ru/5923478/` → HTTP 200, корректно определена кодировка Windows-1251, читается ГОСТ 2060-2006 (латунные прутки).
- `https://metall41.ru/list/list-holodnokatanyj` → HTTP 200, читается товарная страница холоднокатаного листа.
- Скрипт печатает: URL, HTTP-статус, заголовок, кодировку, объём страницы и начало текста. Не решает капчи, не обходит защиты и не утверждает, что весь DOM, JS-таблицы или нормативный документ исследованы. Некоторые сайты требуют отдельного браузерного агента.

Пример запуска на Windows:

```powershell
node "C:\Users\asus\AppData\Local\MagicMetalObsidianSync\competitor-fetch.cjs" "https://metall41.ru/list/list-holodnokatanyj"
```

## Проверенные опорные нормы для следующих подкатегорий

- **Медные и латунные трубы**, ГОСТ 617-2006: действующий стандарт по Росстандарту; латунь в области применения — **Л96**, а не произвольные Л63/ЛС59-1. Источник: https://protect.gost.ru/gost/details/2d836f59-2f3a-4ce0-8546-86b6426c66ba
- **Латунные прутки**, ГОСТ 2060-2006: в нормативном тексте есть пример прутка Л63 диаметром 10 мм. Источник: https://base.garant.ru/5923478/
- **Алюминиевые холоднодеформированные трубы**, ГОСТ 18475-82: действующий по Росстандарту; различаются круглые, квадратные, прямоугольные, фасонные сечения, состояние сплава и форма. Источники: https://protect.gost.ru/gost/details/21b25825-942e-4b04-882d-5a310baf39c5 и https://base.garant.ru/6178590/

Это данные для технического аудита, **не объявление складского ассортимента**. На сайт переносить только после сверки конкретных сочетаний марка × размер × состояние.

## Принцип бесперебойной работы

1. Исследование агента TinyFish, если его команды доступны в конкретном чате.
2. Без TinyFish использовать обычный веб-поиск + локальный загрузчик страниц на Windows.
3. Для сложных JS-страниц — браузер через Remote Desktop Commander или отдельное подключение после настройки; никакой подмены фиктивными данными.
4. Результаты фиксировать в GitHub, существующее зеркало GitHub → Obsidian переносит утверждённые проектные заметки без затирания ручных изменений.
5. Отдельная независимая проверка нормативов до PR/публикации.
