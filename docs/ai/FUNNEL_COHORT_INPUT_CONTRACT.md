# Контракт данных для диагностического роя

Без настоящих сопоставимых визитов **не делаем выводов о потере клиентов**. `scripts/metrika-report.mjs` возвращает агрегаты по целям и страницам; напрямую подставлять их в `prioritize-funnel.mjs` нельзя. Прежде требуется отдельно получить вложенные когорты **уникальных визитов**, одинаковый период и сегмент, проверить смысл целей и исключить роботный/внутренний QA-трафик.

## Пример СИНТЕТИЧЕСКОГО ввода (только для тестирования)
```json
{
  "source": "metrika_aggregated_visits",
  "period": "2026-10-01/2026-10-31",
  "source_report_id": "synthetic-example",
  "robot_filter": "excluded",
  "excludes_internal_qa": true,
  "unit": "distinct_visits",
  "cohort_verified": true,
  "goal_semantics_verified": true,
  "product_visits": 100,
  "request_click_visits": 60,
  "request_started_visits": 50,
  "request_sent_visits": 20
}
```

**Ни одно из этих чисел не является реальным показателем magicmet.ru.** Флаги `*_verified` подтверждаются оператором на основании исходного отчёта, а не самим скриптом. Поэтому при ошибочной декларации правильность подсчёта гарантировать нельзя.

Смысл ступеней: число уникальных визитов с посещением товарной карточки → в **тех же визитах** был переход в заявку → в них же начало заполнения → в них же серверно подтверждённая отправка. Открытие формы через телефон/email — альтернативный путь, его анализировать отдельно. Время визита, просмотры страниц, отдельные достижения целей и данные по регионам без одинаковых когорт не могут заменить эти величины. Низкий трафик — «данных недостаточно», а не указание на конкретную проблему.

Использование: `node scripts/growth/prioritize-funnel.mjs local-aggregate.json local-findings.json`. Файлы с данными сохранять в приватном хранилище и не коммитить. Скрипт ничего не отправляет во внешние сервисы и не меняет сайт.

После получения корректной выборки дополнительная независимая проверка должна подтвердить этап заявка → менеджер → КП → сделка. Только затем брать первое точечное изменение в PR с контролем результата и откатом.
