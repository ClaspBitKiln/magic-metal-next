## Реализация

`scripts/vercel_cleanup.py` — Python 3, только стандартная библиотека. Фиксированная команда `claspbitkiln`, проект `magic-metal-next`, проверка projectId/accountId. Использует штатный proxy, TLS-проверку и системный CA. Токен берётся из `VERCEL_TOKEN`; файлы учётных данных не читаются. Перенаправления API запрещены, ошибки не раскрывают тело ответа/заголовки/токен.

Операции сверены с официальным npm-пакетом `@vercel/sdk` 1.28.58: GET `/v9/projects/{name}`, GET `/v7/deployments`, GET `/v4/aliases`, GET/DELETE `/v13/deployments/{id}`. Пагинация deployments и aliases читается полностью; неполнота, повтор курсора, дубли ID или неизвестная область останавливают работу.

По умолчанию программа только записывает план старых Preview (старше 7 дней, партия 10). Сохраняет все targets проекта, публикации с активными aliases, две последние READY Production, SHA `2f526c5`/`ac643b5`, свежие, активные и неизвестные состояния. Старые Production включаются только явным параметром. План действует 30 минут, максимум 20 кандидатов. В плане только выбранные поля без полного ответа API; план и журнал исключены из Git.

Перед каждым DELETE перечитываются инвентарь и подробности кандидата. Намерение записывается и синхронизируется на диск до запроса. Ошибка записи прекращает работу. Успех запроса записывается отдельно; ошибки API и неоднозначный сетевой исход останавливают партию без автоматического повтора DELETE. `api-delete-accepted` означает успешный ответ API, а не подтверждённое освобождение квоты.

API не предоставляет использованный здесь атомарный условный DELETE: остаётся промежуток между проверкой и удалением, в который другой оператор может назначить alias или выполнить promotion. Перед реальной очисткой не выполнять параллельные назначения доменов/публикации. Абсолютная защита от такой гонки не заявляется.

## Команды для оператора/агента после восстановления доступа

Обычный пользователь не обязан выполнять команды: следующий подключённый агент использует их сам. Значение токена должно передаваться через защищённую настройку среды, не аргументы команды и не Git.

```sh
python3 scripts/vercel_cleanup.py plan --plan /tmp/vercel-cleanup-plan.json
# Прочитать конкретные кандидаты и сохранённые версии.
python3 scripts/vercel_cleanup.py apply --plan /tmp/vercel-cleanup-plan.json --confirm-project magic-metal-next --journal /tmp/vercel-cleanup-journal.jsonl
```

При необходимости инвентаризация более старых Production:

```sh
python3 scripts/vercel_cleanup.py plan --include-old-production --min-days 7 --limit 10 --plan /tmp/vercel-cleanup-plan.json
```

Новый план после каждой партии; не увеличивать объём удаления только потому, что Usage обновляется с задержкой. Конкретные кандидаты реального проекта пока неизвестны. Домены, проект, Neon, Blob и Git программа не удаляет. Сброс накопленного CDN-счётчика, автоматический платный upgrade и покупка ресурсов отсутствуют.
