# Три оформления для закупщика, 17.10.2026

По прямой просьбе показать варианты создана отдельная страница
/catalog-designs.html с тремя отличающимися компоновками:

1. Компактный список: все стенки одного сечения и заявка в каждой строке.
   Высота строки сохраняет область нажатия 44 px без лишних отступов.
2. Карточка закупки: крупный выбранный размер, отдельные параметры
   и заметная область заявки. Для одной известной позиции.
3. Выбор по шагам: два отдельных блока сечения и допустимой стенки,
   затем итог и заявка. Для уточнения неполной спецификации.

Бренд и системный шрифт сохранены. Пример один: 40×20×2 мм,
ГОСТ 8645-68. Цены и наличие не выдумываются и не показываются.
Объяснения «Подходит для» относятся к странице сравнения; в рабочий
покупательский интерфейс эти подсказки не переносились.
Главная и оформление действующего каталога этой пачкой не изменены.

Все варианты интерактивны и используют один снимок 51 сечения исходной
таблицы. Скрипт build-catalog-designs.ts создаёт снимок без source URL;
контрактный тест сравнивает его с исходными строками и примечаниями.
Поиск распознаёт единицы, десятичную запятую и перестановку сторон.
Недопустимое сочетание получает путь проверки с исходным запросом,
без подстановки ближайшего размера. Скобки и оговорка «нерекомендуемый»
сохраняются в видимом результате и заявке. В пошаговом варианте смена
сечения сбрасывает стенку. Форма отправки прежняя, с прикреплением файла.
