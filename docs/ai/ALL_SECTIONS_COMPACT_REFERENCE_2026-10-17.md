# Компактные размеры и связь со справочником — 17.10.2026

Утверждённый сценарий закупщика распространён на все 51 карточку каталога:
обозначение → короткий список основных параметров → полная строка → заявка.
Для 6 карточек без нормативной числовой таблицы сохраняется подбор по спецификации;
числа для них не выдумываются. Всего сохранены 93 исходные таблицы.

## Представление

- Первые 20 строк, затем «Ещё строки»; поиск по обозначению и параметрам.
- В компактном списке обозначение, два первых параметра и заявка;
  полная карточка показывает все исходные колонки без округления.
- В заявке передаются исходные заголовки, значения, таблица и стандарт.
- Диапазоны, допуски и пары стенок остаются буквальными исходными значениями.
- Точная строка сохраняется в URL с идентификатором её содержимого.
- Полные нормативные таблицы доступны отдельным переключателем и без JavaScript.
- Общие шрифты и цвета сайта, компактные строки, мобильная карточка без горизонтального переполнения.

## Справочник

Нативные ссылки из заголовка таблицы и карточки ведут на точную редакцию
стандарта. Квалификаторы «таблица 1/2» и ссылки на несколько документов
разбираются отдельно; год не отбрасывается. Старый ГОСТ не заменяется ссылкой
на новую редакцию автоматически.

Справочник объединяет прежние 31 записи и документы из проверенных данных
каталога — 64 записи. Для добавленных записей не придумываются официальные
названия или статус действия: используются область применения и название
таблицы, статус «Размерные данные в каталоге». Справочник и каталог читают
одни таблицы. Из справочника доступны конкретные карточки продукции с #sizes.
Предзагрузка этих ссылок отключена. Реестр документов не импортируется в
клиентские компоненты. Внешние ссылки на источники не добавлены.
