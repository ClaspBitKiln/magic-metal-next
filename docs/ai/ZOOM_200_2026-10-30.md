# Настоящий масштаб Chromium 200% — 30 октября 2026

Прежние попытки через headless extension и профильные prefs не применили
настоящий browser zoom. Их результаты не являются проверкой 200%.

Использован стандартный headed Chromium на виртуальном экране Xvfb,
нативный X11 ввод: Ctrl+0 и пять Ctrl++. Размер внешнего окна 1536 px.
До: innerWidth=1536, devicePixelRatio=1. После: innerWidth=768,
devicePixelRatio=2, внешнее окно осталось 1536. Это browser zoom,
а не изменение CSS, DPR через emulation или pinch zoom.

[Числовой результат](zoom-check/result.json): zoomRatio=2, overflow=0,
поля формы 13 → 16 CSS px, h1 65,28 → 42 CSS px (адаптивный breakpoint).
Снимки виртуального экрана просмотрены: текст и форма читаемы, поля
не перекрываются и не обрезаны по горизонтали. Для всей длинной формы
используется обычная вертикальная прокрутка. Проверка относится к локальной
production-сборке сайта и странице /#request, не ко всем маршрутам.

Playwright page.screenshot в данном headed-окружении возвращал белую картинку,
поэтому для визуальной проверки использован захват реального X11 экрана
через Pillow ImageGrab. Это ограничение захвата, а не доказанный дефект сайта.
Артефакты вне Git: /workspace/website-finish-tests/native-zoom-x11.png,
native-zoom-form-x11.png и native-zoom.mjs в том же каталоге.

POST и внешняя аналитика блокировались; реальных заявок не было.
Код UI, CSS, hero и защищённый #about не изменялись. Метрика и CMS production
этой проверкой не подтверждаются.
