## СДТ и изоляция — кандидаты на проверку из исследования (НЕ подтверждённый наш каталог)
- Отводы: Dн×s, угол, радиус, марка, ГОСТ 17375; пример 57×3 по каталогу https://magistral74.ru/otvody/otvody-gost-17375-2001/
- Тройники: Dн основной части / Dн ответвления × стенка, ГОСТ 17376, https://magistral74.ru/troyniki/
- Переходы: D1/D2, концентр./эксцентр., ГОСТ 17378, https://www.polycoat.ru/ppu-izolyatsiya/perekhod-v-ppu-izolyatsii.html
- Фланцы: DN / PN / тип / поверхность, ГОСТ 33259, https://magistral74.ru/flantsy/gost-33259-15/
- ППУ: наружный диаметр стальной трубы × толщина стенки / наружный диаметр оболочки, тип 1/2 и материал оболочки, https://metproc.ru/izoljatsija-tryb-ppy-ots-perehodu
- ВУС и эпоксидное покрытие: конструкция, толщина, контроль, а не одно название, https://nkim.ru/vus-izolyacziya/ и https://piktube.ru/catalog/stalnye-truby-v-izolyatsii/epoksidnoe-pokrytie-trub/
Все сайты и числа дополнительно сверять с нормативными текстами; одно исследование ИИ может ошибаться.

## Что выполняется первым
1. Проверка реального прохождения Excel/PDF и сохранения заявки (#99).
2. Независимая техническая сверка СДТ и труб (#94, #93), с частичными PR.
3. Покрытие остальных групп (#95–98), каждый вид минимум два профильных источника и норматив.
4. QA на мобильном, корректная передача размера и марки, публикация только после preview READY / production READY.
5. После проверки перенос этой заметки в Obsidian. Пока файл сохранён в GitHub: для Obsidian API отдельного подключённого инструмента не найдено, поэтому **не считать синхронизированным**.

## Правила отчётности
Для каждого вида товара фиксировать URL, правильную запись обозначения, обязательные параметры, пример размера с источником, марку и стандарт (только подтверждённые), UX-замечание, PR, состояние production. Честно различать **запущенный агент**, **завершённое исследование**, **проверенные нормы** и **опубликовано**.
