## Установленная первопричина прежней пустой или медленной загрузки

Главной подтверждённой причиной был блокирующий внешний импорт шрифта Google в начале общего CSS. Пока внешний ресурс отвечал медленно или был недоступен, браузер задерживал применение стилей, из-за чего страница могла выглядеть пустой или сломанной.

## Оптимизация Vercel

Подготовлена безопасная конфигурация:

- коммиты только с документацией, тестами и QA не запускают лишний Vercel build;
- эти файлы исключаются из deployment context;
- любые изменения `src`, `public`, runtime-данных, зависимостей и конфигурации продолжают запускать полноценную сборку;
- `vercel.json` всегда считается значимым изменением.

Не уменьшается лимит памяти Node вслепую: 4096 МБ относятся к памяти сборки, а не к занятому дисковому хранилищу.

## Устранение белого экрана и ускорение — 29.09.2026, 20:20 (+05)

- Причина в архитектуре старой главной: весь экран был Client Component, а критический контент зависел от гидратации и `motion/react`; при задержке JavaScript страница выглядела непрогруженной.
- PR №43 разделил систему по ТРИЗ: статический контент стал Server Component, JavaScript оставлен только для меню и формы.
- Клиентский JavaScript главной уменьшен примерно с 73 КБ до 14 КБ gzip — более чем в 5 раз.
- Удалена анимационная зависимость из пути главной; LCP-изображению назначен высокий приоритет; аналитика перенесена на idle; локальные логотипы обслуживаются через `next/image`.
- Добавлен production-тест видимости ключевого контента при полностью отключённом JavaScript.
- ESLint: 0 ошибок; тесты формы: 9/9; production build: 140/140 страниц.
