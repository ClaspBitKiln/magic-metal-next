# Цельный hero — 28 октября 2026

## Причина изменения

На соединении пользователя 18 полос загружались частично либо отсутствовали,
в том числе на свежем URL. Их успешная загрузка из облака не подтверждала
исправление в пользовательском Chrome. Причина транспортного сбоя не установлена.

## Простой вариант

- Один полный WebP 640×360, 14 536 байт, с высоким приоритетом загрузки.
- В HTML встроена полная миниатюра 160×90, 1280 байт. Если внешний файл завис,
  видна цельная фотография низкой чёткости вместо белого фона и битых полос.
- Полосы и их CSS удалены с главной. Для hero один сетевой запрос вместо 18;
  новый JavaScript, таймеры и повторные запросы не добавлены.
- Одна схема для mobile/tablet/desktop, прежнее адаптивное кадрирование через CSS.
  Тексты, композиция, типографика и защищённый #about сохранены.
- Генерация: `node scripts/generate-hero-preview.mjs`. Повторные запуски стабильны,
  размер файла и запас HTML-бюджета проверяются до записи.

HTML вместе с текущей аналитикой: 14 465 байт gzip, меньше бюджета 15 000.
Историческая проблема тяжёлого base64 увеличивала HTML до 73 КБ gzip;
здесь миниатюра занимает только 1280 байт и не откладывает body за сетевой порог.

## Проверки

- Полный ESLint и production webpack build прошли.
- Production Chromium smoke: 10 passed; canonical redirect skipped на локальном URL.
- Проверены нормальная фотография, отсутствие JavaScript, отказ всех внешних
  картинок и бесконечно зависший запрос фото. Встроенная миниатюра декодируется.
- Фотография и отсутствие overflow проверены на настоящем local production;
  fault-injection fixture отдельно показывает вариант зависшей передачи.
- `hero-copy` и всё содержимое после него побайтно совпадают с предыдущим commit.
- Реальный browser zoom 200% не проверен; DPR не выдаётся за эту проверку.

## Mobile Lighthouse — локальная лаборатория

По два cold-profile прогона до/после, прежние условия и одинаковая аналитика:

| | 18 полос | Одна фотография |
| --- | --- | --- |
| Performance | 100 / 100 | 100 / 100 |
| FCP | 0,736–0,753 с | 0,875–0,887 с |
| LCP | 1,356–1,360 с | 1,358–1,831 с |
| CLS | 0 | 0 |
| TBT | 9 / 0 мс | 0 / 0 мс |
| Hero-трафик | 46 632 байта | 14 536 байт |

Общий трафик 138 008 → 103 289 байт (−25,2%). Ускорение первого отображения
не заявляется: FCP немного позже, LCP имеет разброс. Выбор — меньше запросов
и цельное изображение при отказе сети. Промежуточный вариант постеров поверх
полос давал 98/100; отчёты сохранены, вариант отклонён в пользу простоты.

Артефакты: `/workspace/hero-diagnostics/performance-simple/`,
`single-photo-*.png`, `single-photo-stall-results.json`, `/tmp/hero-simple-*.log`.
Внешний транспорт этим изменением не исправляется; если запрос зависает,
миниатюра остаётся менее чёткой, а индикатор загрузки браузера может продолжаться.
