# Индексация через IndexNow

`scripts/growth/indexnow.mjs` вручную сообщает участвующим поисковикам об изменённых публичных страницах. Это не регистрация компании в каталогах, не отправка сообщений и не гарантия индексации, позиции или клиентов.

Протокол и ответы проверены 9 ноября 2026: https://www.indexnow.org/documentation . По протоколу поисковики обмениваются принятыми URL. В Google Search Console и Яндекс Вебмастере доступы отдельно не создаются.

## Сначала публикация

В `scripts/growth/indexnow-config.json` сохранены канонический host, фиксированный endpoint и ключ подтверждения домена. Файл `public/3819a7c3731d01e10fdcfca43a3128ac.txt` должен стать доступен на основном домене с тем же содержимым до реальной отправки. Он является публикуемым подтверждением контроля домена, а не паролем пользователя; не добавляйте туда другие секреты.

План без сети и отправки — режим по умолчанию:

```sh
node scripts/growth/indexnow.mjs --revision RELEASE_SHA https://magicmet.ru/postavki/kazakhstan https://magicmet.ru/postavki/uzbekistan
```

После проверки production можно один раз отправить подготовленный набор:

```sh
NODE_USE_ENV_PROXY=1 node scripts/growth/indexnow.mjs --submit --revision RELEASE_SHA https://magicmet.ru/postavki/kazakhstan https://magicmet.ru/postavki/uzbekistan
```

Допускаются 1–100 канонических HTTPS-адресов `magicmet.ru`: главная, продукция, справочники материалов/ГОСТ и поставки. Дубликаты удаляются; query, fragment, credentials, другой host, служебные и неканонические пути отклоняются. До единственного POST проверяются ключ и HTTP200 каждой страницы; редиректы не разрешаются, проверка TLS не отключается.

## Результат и частота

- `accepted` / HTTP200: поисковик получил список; индексация не подтверждена.
- `verification_pending` / HTTP202: список получен, подтверждение ключа ожидается.
- `rate_limited` / HTTP429: остановиться и учитывать `retryAfter`, автоматических повторов нет.
- `retry_later`: срок `Retry-After` предыдущей попытки ещё не наступил; запросы не выполняются.
- `outcome_unknown`: ответ POST потерян или процесс прервался после записи намерения; не повторять вслепую, проверить квитанцию и результат вручную.
- `rejected`: сохранить причину HTTP и исправить условие, а не повторять отправки циклом.

Квитанции JSON пишутся с правами0600 вне Git, по умолчанию `/workspace/.cloud/magic-metal/growth/indexnow/`. Можно задать `MAGICMET_GROWTH_STATE_DIR` или `--receipt /absolute/private/file.json`. Путь внутри репозитория запрещён. Повтор того же набора и revision с успешной квитанцией возвращает `already_submitted` без сети; блокировка файла препятствует одновременным повторным отправкам. Новую revision задавать только для фактического нового выпуска/обновления.

Автоматического расписания нет. Не отправлять неизменные страницы постоянно и не применять инструмент к личным ссылкам, параметрам заявки или чужим сайтам.
