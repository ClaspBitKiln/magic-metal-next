# HTTP-монитор доступности

Workflow `.github/workflows/site-availability.yml` проверяет главную
`https://magicmet.ru` методом HEAD раз в 6 часов: 00:07, 06:07, 12:07 и 18:07 UTC
(05:07, 11:07, 17:07 и 23:07 по Екатеринбургу). Доступен и ручной запуск
через Actions → Site HTTP availability.
Расписание начнёт работать после появления workflow в основной ветке.

План — 4 проверки в сутки. Только при ошибке выполняется одна повторная попытка:
не более двух HEAD-проверок на запуск, каждая ограничена 15 секундами.
Разрешены только HTTPS-переходы (не более трёх), проверка сертификата TLS включена.
Успех требует итогового HTTP 200 и успешного завершения curl.

При двух неудачных попытках job завершается ошибкой; HTTP-код и код завершения
curl остаются в summary запуска. Перезапуск сайта и рассылки не настроены.
Штатные уведомления GitHub об ошибках зависят от настроек владельца.

GitHub может задерживать или пропускать scheduled-запуски; для публичного
репозитория расписания могут автоматически отключаться после 60 дней без
активности. Это HTTP-монитор из сети GitHub, а не гарантия 100% SLA и не
проверка отрисовки, форм, почты или доступности для каждой страны.

Стандартный Linux runner бесплатен для публичного репозитория. Workflow
не скачивает репозиторий, не устанавливает зависимости, не запускает браузер,
не исполняет аналитику и не отправляет заявки. Новых сервисов и секретов нет.
