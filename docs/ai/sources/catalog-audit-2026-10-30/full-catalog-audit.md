## Ключевые выявленные проблемы

- Главная сохраняет дублирующий набор данных в статическом HTML, часть значений динамически заменяется из канонического `productDetailCatalog.ts` при сборке. Целевое состояние: генерировать ВСЮ таблицу из общих типизированных данных без ручного копирования.
- В нескольких позициях (ПВЛ, рифлёный лист, профнастил, катанка, шестигранник, гнутый швеллер, сетки) отсутствуют конкретные параметры/стандарты либо марки. Заполнять только на основании подтверждённой нормативной и ассортиментной матрицы.
- Для общих номенклатур `по спецификации` может быть корректно, если указаны обязательные поля и стандарт выбирается по исполнению.
- Не объявлять наличие и размеры склада без источника.

## Следующие проверки

1. Верифицировать ГОСТ, диапазоны размеров и марки по конкретному типу продукции; отдельно литые и деформируемые сплавы.
2. Добавить проверку всей главной таблицы на отсутствие заглушек, пустых колонок и устаревших значений.
3. Довести прямые URL каждой карточки до 200 и сравнить опубликованные значения с источником.
4. Подтвердить все изменения на magicmet.ru.
