# Котельные трубы: размеры по ТУ14-3Р-55-2001

Пять групп интерфейса соответствуют четырём нормативным таблицам2а–5а
с дополнительным отделением трёх холодных марок12Х1МФ с ограничением D≤70.
ТУ корректно называется ТУ, общий компонент не подписывает его как ГОСТ.
Ошибочная ссылка ГОСТ5520 на листовой прокат удалена из трубного перечня;
ГОСТ32528 обозначен как отдельный сортамент по проекту.
