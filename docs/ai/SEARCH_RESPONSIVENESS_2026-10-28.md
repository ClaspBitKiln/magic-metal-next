# Отзывчивость текстового поиска — 28 октября 2026

## Изменение

В `CatalogSearch` существующий memo индекса теперь хранит товар и заранее
нормализованные заголовок/поисковый текст. Стабильные168 записей (135 базовых
и33 дополнительных стандарта) обрабатываются один раз при изменении индекса,
а не заново при каждом символе или переключении типа результата.

Условия совпадения, вычисление рейтинга, сортировка, сами SearchItem, URL,
фильтры и API размеров не меняются. Нет нового debounce, библиотеки, запроса,
CSS или разметки. Главная и жирные синие контакты не затронуты.

## Проверки и границы

- 360 вариантов запрос/фильтр (префиксы восьми текстов × четыре фильтра):
  полное сравнение упорядоченных объектов до/после совпало. Benchmark извлекает
  реальные callbacks компонента, а не копирует алгоритм вручную.
- Четыре существующих профильных теста запросов прошли; повторного полного
  аудита сайта не проводилось. ESLint и production webpack build прошли.
- Изолированный CPU benchmark:7 чередующихся прогонов,1440 операций в каждом,
  медиана2008,10→80,27ms (~96% меньше времени именно этого участка).
  Подготовка индекса один раз заняла7,25ms и записана отдельно. Это не означает
  ускорение всей страницы на96% и не является полевым INP.
- Артефакты `/workspace/search-response-study/`: исходный callback и benchmark,
  результаты сравнения, профиль типографики. Browser EventTiming измеряется
  отдельно с CPU×4; сетевые/DOM/отрисовочные затраты не исчезают от этой правки.
- Главная: тот же HTML, gzip13312Б, один прежний home.js (без аналитического
  инжекта); это локальное сжатие, не переданный объём. Production Brotli уже
  подтверждён в предыдущем отчёте1ebae18, runtime compression не менялся.

## Публикация

Профильный GitHub Actions workflow теперь автоматически запускается при правке
главной, CatalogSearch или файлов страницы поиска, а не только при изменении
собственного YAML. Сохраняются прежние14 публичных проверок (12 главной,2 SSR поиска).
Отчёт с sourceCommit итоговой версии — подтверждение выполнения live-проверок.
